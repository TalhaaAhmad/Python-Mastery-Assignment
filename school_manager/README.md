# School Manager
1. Install Python 3.10 or newer and open a terminal inside the school_manager folder.
2. Install the tools: pip install -r ../requirements.txt
3. Run the program: python main.py (data is saved in school.json when you choose 5)
4. Run the tests: pytest -v
5. Option 6 writes a teacher comment using simple rules (the AI bonus was not done).
